# Architecture

AeroSec Tower is a lightweight simulation platform for a DevSecOps aviation monitoring memoire project.

## Layers

- React frontend renders the enterprise dashboard, monitoring pages, security views, logs, and pipeline visualization.
- Express backend exposes protected REST APIs and emits simulated realtime telemetry through Socket.io.
- PostgreSQL stores demo users, logs, alerts, system status, and audit events.
- PostgreSQL stores demo users, logs, alerts, system status, audit events, and deployment states.
- Docker Compose starts the complete local environment.

## Security Model

- Passwords are hashed with bcrypt.
- API routes are protected with JWT middleware.
- Role checks protect administrative endpoints.
- Helmet, CORS, rate limiting, and input validation are enabled.

## Simulation Model

Realtime events are generated by the backend every few seconds. Data is intentionally fake and safe for educational use.

## DevSecOps Context

The runtime app stays lightweight: frontend, backend, and PostgreSQL. The pipeline visualization models the target infrastructure: GitHub Webhooks, Jenkins, SonarQube, Trivy, OWASP ZAP, Docker Build, single-node k3s, and AWS EC2 deployment.

The AI feature is represented as a deployment decision assistant. It consumes simulated quality, vulnerability, ZAP, container, and deployment signals and returns a risk score plus a decision such as approve or manual-review.
